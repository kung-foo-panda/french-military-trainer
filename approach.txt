# 4️⃣ The Extreme Repetition Algorithm

This is the core.

We do NOT implement classic SM-2.
We implement aggressive adaptive decay.

---

## Core Principles

1. Strength increases slowly.
2. Strength drops aggressively.
3. Failure multiplies exposure.
4. Weakest 20% dominate session.
5. Overdue concepts override everything.

---

## Strength Update Logic

If correct:

```
strength += 5
stability += 1
```

If wrong:

```
strength -= 20
failureCount += 1
stability = 1
```

No mercy.

---

## Scheduling Logic

Next review interval:

```
interval = baseInterval * stability
```

But if failureCount > 2:

```
interval = 1 day
```

If strength < 40:

→ reinsert into same session.

---

## Session Selection Logic

When session starts:

1. Fetch all concepts
2. Sort by:

   * Overdue first
   * Lowest strength next
   * Highest failureCount next
3. Select top 20

No randomness.

No comfort.

---

# 5️⃣ Session Structure (Military)

Daily minimum: 25 exercises
Minimum time: 20 minutes
No skipping allowed

Session flow:

```
while session not finished:
   generate exercise from weakest concept
   evaluate
   update strength
   reschedule
```

If session aborted:
→ next day doubles minimum.
