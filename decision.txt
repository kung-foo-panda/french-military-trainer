# 🧠 SYSTEM BLUEPRINT

**Project Name (working):** French Intensive Trainer

---

# 1️⃣ Core Philosophy

This is NOT Duolingo.

It is:

> 🎯 Grammar-driven, drill-heavy, adaptive, weakness-focused training system.

It must:

* Force production (typing, not clicking)
* Track errors precisely
* Repeat weak patterns
* Increase difficulty automatically
* Feel intense but structured

---

# 2️⃣ High-Level Architecture (Web MVP)

### 🖥 Frontend

* React (Next.js preferred)

* Local state + Firebase sync

### ☁ Backend

* Firebase:

  * Firestore (data)
  * Auth (optional for now)
  * Hosting

No custom server needed initially.

# 4️⃣ Core Modules

## Module 1 — Grammar Structure Layer

Structured representation of your PDF.

Instead of PDF → convert into:

```ts
GrammarModule {
  id: "passe_compose",
  title: "Passé Composé",
  level: "A2",
  rules: [],
  exerciseTypes: []
}
```

You manually encode grammar progressively.

---

## Module 2 — Exercise Engine (The Brain)

This is the most important part.

Exercise types:

1. Conjugation
2. Fill in blank
3. Sentence transformation
4. Agreement correction
5. Error detection
6. Free typing (advanced later)

---

### Example Exercise Object

```ts
Exercise {
  id: "pc_001",
  type: "conjugation",
  prompt: "Conjugate: être (nous) in passé composé",
  correctAnswer: "nous avons été",
  metadata: {
    verb: "être",
    tense: "passe_compose",
    auxiliary: "avoir"
  }
}
```

---

# 5️⃣ Dynamic Exercise Generator (Important)

Instead of static exercises:

You build **generators**.

Example:

```ts
generatePasseComposeExercise() {
  pick random verb
  pick random subject
  determine auxiliary
  build expected answer
}
```

Now you get unlimited drills.

This is what makes it intensive.

---

# 6️⃣ Evaluation Engine

Strict comparison at first.

Later:

* Accent tolerance
* Minor typo tolerance
* Case normalization

Evaluation result:

```ts
EvaluationResult {
  correct: boolean,
  errorType: "auxiliary_error" | "agreement_error" | "spelling_error"
}
```

This is crucial for weakness detection.

---

# 7️⃣ Weakness Tracking System

Instead of just correct/incorrect:

Track:

```
Verb: être → 60% accuracy
Tense: passé composé → 72%
Agreement rule → 45%
```

Store stats per:

* Verb
* Tense
* Rule
* Exercise type

This enables adaptive repetition.

---

# 8️⃣ Spaced Repetition Layer

Each concept gets:

```
score
lastSeen
nextReviewDate
difficultyWeight
```

Basic algorithm:

If correct:
→ increase interval

If wrong:
→ reset interval shorter

You can implement simplified SM-2 later.
